# Security / امنیت

Please **do not** open a public issue for security problems.
Report them privately via [@LinkPortaSup_Bot](https://t.me/LinkPortaSup_Bot) or GitHub's *Report a vulnerability* button on this repository.

لطفاً مشکلات امنیتی را به‌صورت عمومی (Issue) مطرح نکن؛ از طریق [@LinkPortaSup_Bot](https://t.me/LinkPortaSup_Bot) یا دکمه‌ی *Report a vulnerability* همین مخزن خصوصی گزارش بده.

Only download LinkPorta from this repository's Releases or the official Chrome Web Store listing, and check the `.sha256` file.
